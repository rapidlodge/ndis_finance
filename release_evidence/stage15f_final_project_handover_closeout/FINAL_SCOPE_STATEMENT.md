## Out of Scope

The following are not performed within this project closeout:

- production activation
- live Payment Entry posting enablement
- production mode enablement
- live_posting_allowed enablement
- new governed implementation cycle
- Phase 14V
- new business capability outside governed payment posting

## Future Scope Boundary

Future work must be separately approved if it introduces:

- production activation
- live posting
- a new funding/payment capability
- a new accounting document type
- an integration with external finance systems
- a new governed implementation cycle outside current scope

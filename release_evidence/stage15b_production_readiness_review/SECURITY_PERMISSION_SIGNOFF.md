# Security and Permission Sign-Off

## Scope

Governed payment-posting permissions and release safety.

## Required Checks

- [ ] Final runtime monitor execution permission reviewed
- [ ] Audit cancellation permission reviewed
- [ ] Production activation permission reviewed
- [ ] Live posting permission reviewed
- [ ] No unauthorized role can execute governed posting
- [ ] No unauthorized role can cancel governed audit evidence
- [ ] No unauthorized role can change controlled policy state
- [ ] No unauthorized role can enable production mode
- [ ] No unauthorized role can enable live Payment Entry posting

## Known Required Roles

- System Manager
- NDIS CFO
- NDIS Finance Manager for audit cancellation where applicable

## Sign-Off

- [ ] Security/permission review approved
- [ ] Permission matrix ready for production readiness review
